Setup guide

  1. Create the repository. On GitHub, create leetcode-solutions (public or private) and tick “Add a README file” so the default branch exists.
  2. Create a fine-grained token. Open GitHub → Settings → Developer settings → Fine-grained tokens. Choose your personal account as the resource owner and set an expiration.
  3. Restrict it. Under Repository access choose “Only select repositories” and pick only the destination repository.
  4. Grant one permission. Under Repository permissions set Contents to “Read and write”. Leave everything else at “No access” (Metadata: Read-only is added automatically).
  5. Save it here. Paste the token above and click Save token. Never paste it anywhere else.
  6. Test the connection and fix anything it reports.
  7. Save settings, then submit a solution on leetcode.com.

Permissions and privacy

  • storage: keeps your settings, token and sync history in this browser profile.
  • alarms: wakes the extension to retry a failed sync with backoff.
  • api.github.com: the only host the extension sends requests to with your token.
  • leetcode.com content scripts: watch for your accepted submissions and read that submission back from LeetCode. Nothing on other sites is read.

A token stored in a browser extension is protected by your OS account and Chrome profile, not by encryption the extension controls. Anyone with access to this profile could extract it. Keep the token limited to one repository and give it an expiration.

If the token may be exposed, revoke it at github.com/settings/personal-access-tokens, then click “Remove stored token”.
